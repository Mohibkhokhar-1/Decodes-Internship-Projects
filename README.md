# Python Chatbot

This is a simple chatbot made using Python. It takes input from the user and gives replies based on the message entered.

## Features

* Simple text conversation
* Takes user input
* Gives different responses
* Runs continuously until the user exits
* Beginner-friendly Python project

## How to Run

First, make sure Python is installed on your computer.

Run the following command:

```bash
python chatbot.py
```

Then start chatting with the bot.

## Example

```text
Chatbot: Hello! How can I help you?
You: hello
Chatbot: Hi! Nice to meet you.

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
```

## Technologies

* Python
* While Loop
* If-Else Conditions
* User Input

I made this project to practice Python loops, conditions, user input, and basic chatbot logic.
